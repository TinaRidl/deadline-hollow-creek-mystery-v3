# DEADLINE — The Hollow Creek Murder

An interactive, English-language mystery website for Vercel + GitHub.

## Files
- `index.html` — main game website
- `api/chat.js` — GPT-4o mini interview endpoint
- `api/verdict.js` — checks the murderer name
- `api/case.js` — server-side case rules and character knowledge
- `assets/` — portraits and scene illustrations
- `vercel.json` — Vercel config
- `package.json` — project metadata

## Deploy on Vercel
1. Upload all files to GitHub.
2. Import the repository into Vercel.
3. Add the environment variable `OPENAI_API_KEY`.
4. Deploy.

## Notes
- The game is fully in English.
- Jamie the ghost does not use chat. He appears as pop-up hints and his clues are stored in the Spirit File.
- The murderer is Evelyn Price.
